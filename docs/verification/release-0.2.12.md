# 0.2.12 검증 기록 (앱 아이콘만 변경)

0.2.11(`463798f`) 대비 달라진 것은 디자이너 앱 아이콘(라이트·다크)과 버전 표기(0.2.12, versionCode 14, `assets/schema.json` version)뿐이다. 엔진·내비·음성·서버 연동 코드는 바꾸지 않았다.

## 확인한 것 (2026-11-14)

- 단위 테스트 87개 통과. `assembleDebug`·서명 `assembleRelease` 성공.
- 서명 release의 인증서 SHA-256이 0.2.11 release와 같다(`f888bfaf…d111`). 0.2.11 위에 `adb install -r`로 업데이트된다.
- Pleos 에뮬레이터(0.2.10 debug)와 Galaxy S10 5G에서 라이트·다크 아이콘이 시안대로 나온다. 삼성 런처 마스크에서 핀이 잘리지 않는다.
- 에뮬레이터에서 "다른 앱 위에 표시" 권한을 준 상태로 내비 위 웨이팅 카드가 뜨는 것을 다시 확인했다(0.2.10 debug 빌드 기준).

## 확인하지 못한 것

- 0.2.12 서명 release의 전체 시연 흐름(접수·하차·호출)은 다시 돌리지 않았다. 코드 변경이 없어 0.2.11 기록([release-0.2.11.md](release-0.2.11.md))을 그대로 따른다.
- 다크 아이콘은 런처가 시스템 다크 모드를 따를 때만 바뀐다. 네이비 타일은 검정 하단 바에서 경계가 거의 보이지 않는다(Figma 색상 그대로).
